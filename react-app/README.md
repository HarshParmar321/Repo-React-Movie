# React Movie App

This project is a simple React application that displays a list of movies. When a movie is clicked, it navigates to an individual movie page that displays the same content for each movie.

## Project Structure

```
react-app
├── public
│   └── index.html          # The main HTML file
├── src
│   ├── components          # Reusable components
│   ├── pages
│   │   └── Movie
│   │       └── index.jsx   # Individual movie page component
│   ├── App.jsx             # Main application component
│   ├── index.js            # Entry point of the application
│   └── index.css           # Global styles
├── package.json            # npm configuration file
└── README.md               # Project documentation
```

## Installation

1. Clone the repository:
   ```
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```
   cd react-app
   ```
3. Install the dependencies:
   ```
   npm install
   ```

## Usage

To start the application, run:
```
npm start
```
This will start the development server and open the application in your default web browser.

## Features

- Displays a list of movies.
- Individual movie pages that show the same content when a movie is clicked.
